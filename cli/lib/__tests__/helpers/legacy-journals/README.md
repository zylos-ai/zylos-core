# Historical Terminal Journals

These fixtures preserve the field structure of three completed real protected
upgrades: 0.9.0 to 0.9.0, 0.9.0 to 0.9.1, and 0.9.1 to 0.9.2. They were supplied
with the independent review of the protected upgrade implementation.

Machine paths, transaction identifiers, process identifiers, hashes, skill names,
and service names have been replaced with deterministic test values. No retained
recovery scripts are executed. Each journal has three original databases,
completed cleanup, verified terminal evidence, and no recoveryHashes field.
